# ALS UI

The frontend uses Vue 3, TypeScript and Vite, styled with Tailwind CSS v4 and
[shadcn-vue](https://www.shadcn-vue.com/) components (built on Reka UI). Use Node.js 24.22.1
(see [.nvmrc](.nvmrc)) and npm.

From the repository root, initialize the LibreSpeed submodule before building:

```sh
git submodule update --init --recursive
```

Run the following commands from `ui/`:

```sh
npm ci
npm run dev
```

The development server proxies `/session` and `/method` to the backend at `http://127.0.0.1:8080`.

To check and build the frontend:

```sh
npm run lint       # ESLint with typescript-eslint recommendedTypeChecked
npm run typecheck  # vue-tsc
npm test           # node:test, running the .ts tests natively
npm run build      # vue-tsc + vite build
```

Use `npm run lint:fix` for automatic lint fixes or `npm run format` to format source files. Commit `package-lock.json` whenever dependencies change so local, Docker, and GitHub Actions builds install the same versions.

## Project layout

- `src/components/ui/` — shadcn-vue primitives generated by the CLI (`npx shadcn-vue@latest add <name>`,
  configured by [components.json](components.json)). Treat them as vendored code: they are excluded from
  ESLint and Prettier so they can be regenerated without churn.
- `src/components/` — application components. New code should be TypeScript (`<script setup lang="ts">`).
- `src/composables/` — theme (light/dark/system, persisted), clipboard and chart theming helpers.
- `src/helper/` — framework-free logic with unit tests (`*.test.ts`).
- `src/assets/base.css` — Tailwind entry point and the design tokens (CSS variables) for both themes.

To embed the frontend in a local backend build, run these commands from the repository root with Go 1.27.3:

```sh
cp -R ui/dist/. backend/embed/ui/
go -C backend build -o ../tmp/als .
```
